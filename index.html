1. 総合ポイントの仕組み

総合P ＝ スコアP ＋ ゲームP（小技） ＋ アトラクションP ＋ ラスベガスP

2. スコアP（ネット基準・減点なし！）

グロス打数から各自のハンディを引いた「ネット」で判定：

  • 🦅 イーグル以上: ＋3P
  • 🐥 バーディ: ＋2P
  • ⚪ パー: ＋1P
  • △ ボギー以下（ダボ、トリプル等）: 0P（マイナスなし！）

3. ゲームP（小技ボーナス ＆ 罰符）

  • 💎 チップイン: ＋5P
  • 🥇 金パット（最長）: ＋4P
  • 🥈 銀パット: ＋3P
  • 🥉 銅パット: ＋2P
  • 💥 罰符（OB / 池 / バンカー / 3パット）: 各 −1P

4. ニアピン・ドラコン（上限＆重複ブレーキ）

  • 基本配点：10P（該当者なしは持ち越し）
  • キャリー上限: 最大20Pまで（それ以上は加算ストップ）
  • 重複ペナルティ:
    • 同一タイトル1回目：満額（10P または キャリー最大20P）
    • 同一タイトル2回目：半減（5P）
    • 同一タイトル3回目以降：0P（名誉のみ）
    • ※キャリー(20P)獲得者は、次回同一タイトル獲得時は0P。

5. ラスベガス対戦（ペア順位戦）

上位・中位・下位をクロスさせたペアの2桁ネット数字で勝負：

  • 1位ペア：各 ＋3P
  • 2位ペア：各 ＋2P
  • 3位ペア：各 ＋1P
  • ※バーディ倍付け反転なしの健全設計。
